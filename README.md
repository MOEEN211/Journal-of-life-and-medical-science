# Journal of Life and Medical Science (JLMS)

An international, peer-reviewed, open-access academic journal platform publishing high-impact clinical, epidemiological, biomedical, and translational medicine research.

## Features
- **Modern Academic UI**: Built with elegant academic styling, typography, and responsive layouts.
- **Dynamic Database Layer**: Powered by Supabase for real-time article publishing, issue management, and author submissions.
- **Editorial Admin Dashboard**: Complete submission review, article publication, and management portal.
- **Automated Email Notifications**: Full EmailJS integration for submission confirmations, review feedback, and acceptance notifications.
- **Citation Export**: Instant citation generation (APA, MLA, Chicago, Harvard, IEEE, Vancouver) and RIS/BibTeX export.

## Running Locally
```bash
# Start the local server
node server.mjs
```
The application will be served at `http://localhost:4100/`.
- Main Portal: `http://localhost:4100/index.html`
- Admin Dashboard: `http://localhost:4100/admin.html`
